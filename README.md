# NOVA DIGITEX — primera versión web

## Abrir
La aplicación está en index.html. Es adaptable a pantallas Windows y Android.

## Incluye
- 11 rubros con POS de demostración independiente.
- Carrito, cantidades, medios de pago y registro local de ventas.
- Historial local y exportación CSV.
- Inventario ilustrativo, clientes y estadísticas.
- Manifest PWA básico.

## Limitaciones importantes
Este es un MVP de demostración, no software listo para producción. Los precios y existencias son datos de ejemplo. Las ventas y clientes se guardan solo en el navegador/dispositivo. No hay aún servidor SQL, sincronización real entre equipos, autenticación robusta, permisos efectivos, auditoría, copias de seguridad, impresoras integradas ni emisión electrónica SUNAT. No registrar datos reales sensibles ni usar para ventas reales hasta implementar y probar esas funciones.
